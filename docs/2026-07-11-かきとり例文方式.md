# かきとりクイズを「例文（文脈）方式」に変更 — 実装の記録

- 日付: 2026-07-11
- 依頼: 「計らう のように同じ読みで漢字が複数ある字は、文章の文脈でないと判断できない。文章は一文でいいので、文例を用いながら書き取りクイズになるように変更してほしい」
- 結論: **かきとりクイズ `kaki/index.html` を〈一文の例文＋読み＋□送りがな〉方式に変更して公開済み**。同じ読み・同じ送りがなの語（はかる＝計る/図る 等）が、例文の意味で漢字一つに決まるようになった。

---

## 1. 何を変えたか（ひとことで）

これまでは「あかるい」＝ □るい のように**読みと送りがなだけ**を見せていた。これだと「はかる」のように同じ読み・同じ送りがなで漢字が複数ある語（計る／図る）は、どの漢字が正解か決められない。そこで**一文の例文**を足して、文の意味で漢字が一つに決まるようにした。

- 例：「ストップウォッチで タイムを □る。」／読み「はかる」→ **計る**
- 例：「みんなの あんぜんを □る。」／読み「はかる」→ **図る**

読み（「はかる」）と □送りがな は今までどおり残している（小2向けに、文脈と読みの両方を手がかりにできる）。

## 2. なぜこの形にしたか（判断の経緯）

依頼前に本人へ2点確認し、どちらも推奨案が選ばれた。

1. **例文をどの範囲に付けるか** → 曖昧な31語だけでなく**全131語に付ける**。問題の見た目が2種類混在するのを避け、体験を統一するため。
2. **読みのヒントを残すか** → **残す**。小2には文脈だけで読みまで判断させるのは重い。文は「どの漢字か」を決める役、読みは「なんと読むか」を示す役、と役割を分けた。

あわせて、旧仕様の「※ 〜と書いても⭕だよ」という**別解の併記は廃止**した。例文で答えを一つに絞る方針と正面から矛盾する（「タイムを計る」の文で「図る」を⭕にしてしまう）ため。

## 3. 部品と仕組み（非エンジニア向け）

- **例文データ＝新規ファイル `kaki/sentences.js`**。中身は「語 → 一文の例文」の対応表（`KAKI_SENTENCES`）。全131語ぶん手作りした。
  - 例文の中の `@@` が、答えの語が入る**空らん**の位置。画面では未回答なら「□＋送りがな」、こたえ合わせ後は「漢字＋送りがな」に置きかわる。
  - **答えの漢字は例文に書かない**（答えがバレないよう、例文は基本かなで書いた。小2が読める語彙にそろえた）。
  - 同じ読み・同じ送りがなの組（あう＝会う/合う、かう＝買う/交う、はかる＝計る/図る）は、**文の意味で必ず一方に決まる**ように文を選んだ。
- **問題は今も自動生成**。出題語じたいは従来どおり漢字マスタ `shared/kanji-db.js` の訓読みから作る。例文はそこへ「語ごとの一文」を重ねているだけ。漢字を足したら、例文も1語ぶん `sentences.js` に足す運用。
- **画面の変更**（`kaki/index.html`）：出題カードに例文の行 `#qsentence` を追加。描画は `renderSentence()` が担当（未回答＝□送りがな／回答後＝漢字を埋めた文を表示）。`makeQuestion()` は各問に例文を持たせ、別解 `alts` は空にした。あそびかたの説明文も例文方式に更新（計る／図るの例を明記）。
- **検証の自動化を強化**（`validate.mjs`＋`tools/lib.mjs`）：
  - 出題プールの**全語に例文があるか**（抜けを検知）
  - 例文に**空らん `@@` があるか**
  - **答えの漢字が例文に出ていないか**（答えバレ検知）
  - プールに無い語の例文（消し忘れ）の検知
  - `tools/lib.mjs` に `loadKAKISENTENCES()`（例文の読み込み）と `kakiPoolWords()`（アプリと同じロジックで2年生プールを再現）を追加。

## 4. 検証（実行したこと）

- `node validate.mjs` → **かきとり例文 131/131語（全語あり）・リーク0・全チェック合格**（exit 0）
- inline JS（`kaki/index.html` の本体スクリプト）を `node --check` で構文チェック → OK
- `renderSentence` のロジックを Node で再現し、区別が必要な語の表示を確認：
  - 計る＝「タイムを□る」／図る＝「あんぜんを□る」、会う／合う、買う／交う、明るい・明ける・明く・明くる・計らう が未回答／回答後とも正しく表示
- 全131語について「答えの漢字が例文に無い」を再確認（リーク0）
- `deploy.sh` で公開後、**CI（validate.yml）success**
- 補足：この回はブラウザ拡張が未接続だったため、実ブラウザでの目視確認は未実施。表示ロジックは Node で再現して確認した。

## 6. 残っている論点（未対応・要望あれば対応）

- 訓読みが公式配当由来のため、**語じたいがまれな数語**（明く・来す・古す・交う・分かつ・強いる）は例文がやや硬い。実際に子どもに出して不自然なら、その語だけ `kaki/sentences.js` の一文を差し替える（データ1行の修正で済む）。
- 学年拡張（`KAKI_POOL` を2年以外にも広げる）時は、増えた語の例文も `sentences.js` に足す必要がある（`validate.mjs` が抜けを検知するので気づける）。
